# Coding agents on ChannelVault

ChannelVault is Jason Baron's independently maintained personal fork of Tube Archivist. The owner authorizes coding agents to implement, review, document, and test changes in this fork. This policy replaces the inherited upstream agent restrictions, preserved for reference in UPSTREAM_AGENTS.md.

- Follow the owner's instructions and keep changes focused on the requested scope.
- Preserve the GPLv3 license, original copyright notices, and upstream attribution.
- Keep documentation accurate about implemented features and future plans.
- Preserve API, storage, configuration, and metadata compatibility unless a migration is explicitly requested.
- Do not expose secrets or modify live deployments without authorization.
- Run checks appropriate to each change and report untested behavior.
- Do not commit, push, publish, or contact upstream maintainers unless explicitly requested.
- Use direct, practical language. Do not use em dashes.

See CONTRIBUTING.md for development guidance.
